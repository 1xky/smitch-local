Smitch Local for macOS

1. Extract this ZIP.
2. Install Python 3.10 or newer if needed.
3. Open Start-Smitch.command.
4. Keep the launcher window open while using the controller.

If macOS blocks it the first time, Control-click Start-Smitch.command, choose Open, and confirm.
The controller opens at http://127.0.0.1:8765 and requires no Python packages.
